Advanced settings

Passed through as claude's --permission-mode. Careful with acceptEdits: anyone who submits a task can make the agent write in its workdir — only use it with a sandbox workdir. ⚠ bypassPermissions goes much further: the agent runs any command without asking, so anyone who can submit a job can execute arbitrary commands on this machine — reserve it for agents that truly need it (e.g. running git/tests to fix a PR) and you'll be asked to confirm. --visible and HMAC stay CLI-only: the first breaks the result callback and the second arrives in phase 2 — for those, create the hook with awb add and use the "I already have a hook" mode.
